# fentanyl BETA — полное руководство от А до Я

🇬🇧 **English version: [README.en.md](README.en.md)** · 🇷🇺 Русская версия — этот файл.

Консольный ИИ-помощник для программирования (замена Codex / Claude Code).
Создатель: **SlimeCat** · сделано с помощью **Claude** (Anthropic).

> Версия **BETA**: возможны баги. Проверено на Linux с Python 3.12. На Android (Termux), Windows и macOS
> специально не тестировалось — если что-то не так, смотри раздел «Если что-то не работает».

---

## 1. Что умеет

- Чат с ИИ в терминале, ответ печатается по ходу, код — в рамках.
- **Агент**: ИИ сам предлагает создать/изменить файлы и выполнить команды. Ты подтверждаешь `y` / `n` / `a`.
- Работает **в папке, которую выбрал ты** (не в корне диска), есть меню проектов.
- **Автопроверка**: после работы ИИ запускает проект, смотрит ошибки в консоли и либо предупреждает, либо сам чинит.
- **Окно предпросмотра**: вывод программы (Python / Node / sh) или страница HTML в браузере.
- Работает с облачными ИИ (Anthropic, OpenAI, OpenRouter) и с локальными (Ollama, LM Studio, встроенный GGUF).
- **Два языка интерфейса: English и Русский** (выбор при первом запуске, смена командой `/lang`).
- Имя, приветствие по времени суток, темы, анимации, котик, сброс настроек.

## 2. Что нужно скачать и установить

### Обязательно
| Что | Зачем | Где взять |
|---|---|---|
| **Python 3.8 или новее** (проверено на 3.12) | запуск программы | python.org (Windows/macOS), `pkg install python` (Termux), `sudo apt install python3` (Linux) |
| **Эта папка `fentanyl`** | сама программа | распакуй zip куда угодно |

Больше ничего ставить не нужно: программа использует только стандартную библиотеку Python (`pip install` не требуется).

### Нужен один из вариантов ИИ (выбери любой)
| Вариант | Нужно | Интернет |
|---|---|---|
| **Anthropic / OpenAI / OpenRouter** | API-ключ | нужен |
| **Ollama** | программа Ollama + скачанная модель | только для скачивания |
| **LM Studio** | программа LM Studio + модель | только для скачивания |
| **GGUF (встроенный)** | `llama-server` (из llama.cpp) + файл модели `.gguf` | только для скачивания |

### Необязательно
| Что | Зачем |
|---|---|
| **Node.js** | проверка и запуск `.js` проектов |
| **Git** | команда `/git` |
| **Termux:API** (приложение) + `pkg install termux-api` | уведомления и режим экономии батареи на Android |

## 3. Установка по платформам

### Android (Termux)
```bash
pkg update
pkg install python
# распакуй fentanyl.zip (например в ~/fentanyl) и перейди в папку:
cd ~/fentanyl
python fentanyl.py
```
Хочешь запускать локальную модель на телефоне — см. раздел 5, вариант «GGUF».

### Windows
1. Установи Python с python.org (поставь галочку **Add Python to PATH**).
2. Распакуй zip.
3. Открой **Windows Terminal** (или PowerShell) в папке `fentanyl` и выполни:
```powershell
python fentanyl.py
```
Старое окно `cmd` может плохо показывать цвета и рамки — лучше Windows Terminal.

### macOS / Linux
```bash
cd fentanyl
python3 fentanyl.py
```

## 4. Первый запуск — по шагам

1. **Экран загрузки** с логотипом (~3 секунды), потом он исчезает.
2. **Выбор языка** (первый экран, на английском): `1` — English, `2` — Русский. Дальше весь интерфейс на выбранном языке. Сменить можно в любой момент: `/lang`.
3. Появляется шапка с логотипом в углу.
4. **Подключение ИИ** (только при первом запуске): выбери номер провайдера (раздел 5).
5. **Как к тебе обращаться?** — введи имя или псевдоним. Enter — пропустить.
6. **Папка проекта** — выбери, где будет работать ИИ:
   - `Enter` — первая строка (последняя использованная или текущая);
   - номер — один из пунктов списка;
   - `b` — обзор папок;
   - или просто введи путь.
7. **Приветствие** с твоим именем (анимация), и можно писать запрос.

Можно сразу указать папку при запуске: `python fentanyl.py путь/к/проекту`.

## 5. Подключение ИИ

Меняется в любой момент командой `/setup`. Настройки хранятся в файле `~/.fentanyl.json`.

### Anthropic (Claude)
1. Зарегистрируйся на console.anthropic.com и создай API-ключ.
2. В `/setup` выбери **1**, вставь ключ (при вводе он не показывается), адрес и модель оставь по умолчанию (Enter).

### OpenAI
1. Ключ: platform.openai.com → API keys.
2. В `/setup` выбери **2**.

### OpenRouter (много моделей одним ключом)
1. Ключ: openrouter.ai → Keys.
2. В `/setup` выбери **3**, модель укажи в формате `производитель/модель`.

### Ollama (локально, бесплатно)
1. Установи Ollama с ollama.com.
2. Скачай модель: `ollama pull qwen2.5-coder`.
3. В `/setup` выбери **4**. Адрес по умолчанию `http://127.0.0.1:11434/v1`.

### LM Studio (локально, с окном)
1. Установи LM Studio, скачай модель, включи **Local Server** (порт 1234).
2. В `/setup` выбери **5**.

### GGUF (встроенный, программа сама запускает сервер)
1. Нужен **`llama-server`** из проекта llama.cpp:
   - Termux: `pkg install llama-cpp`;
   - другие системы: скачай готовую сборку llama.cpp с github.com/ggml-org/llama.cpp (раздел Releases) или собери сам, и положи `llama-server` в `PATH`.
2. Нужен файл модели `.gguf`. Проще всего внутри программы: команда **`/models`** → выбери модель из каталога (Qwen2.5-Coder 0.5B / 1.5B / 3B / 7B, Llama 3.2 1B / 3B) — она скачается в папку `~/models`. Либо положи свой `.gguf` в `~/models` или в папку загрузок, либо скачай по ссылке: `/download <ссылка>`.
3. В `/setup` выбери **6** и номер модели (или путь к файлу). Дальше сервер запускается и останавливается сам.

Ориентир по железу: 0.5B–1.5B — слабые телефоны; 3B — от 6 ГБ памяти; 7B — от 8 ГБ.

### ИИ на компьютере, а программа на телефоне
На телефоне адрес `127.0.0.1` — это сам телефон. Укажи IP компьютера в Wi-Fi (например `http://192.168.1.50:11434/v1`). На компьютере сервер должен принимать подключения из сети (для Ollama — переменная `OLLAMA_HOST=0.0.0.0`, для LM Studio — опция доступа из локальной сети).

## 6. Как работать

**Пиши обычным текстом.** Примеры:
```
создай сайт-визитку на HTML и CSS
добавь в @main.py обработку ошибок
объясни, что делает @src
```

- **`@путь`** прикрепляет файл или папку к сообщению. Можно несколько. Пути — от папки проекта (абсолютные тоже работают).
- Строка, оканчивающаяся на `\`, — продолжение ввода. Много строк сразу: `/paste` (закончить строкой `END`).
- **Ctrl+C во время ответа** — остановить. **Ctrl+C на пустой строке** — предупреждение, второй раз за 2 секунды — выход.

### Агент и подтверждения
ИИ предлагает действия, ты отвечаешь:
- `y` — да, `n` — нет, `a` — всегда (до конца сессии).
- Перед правкой показывается diff (что было → что стало).
- **`/undo`** откатывает последнюю правку файла.
- `/auto edit` и `/auto run` — не спрашивать подтверждение (`/auto off` — вернуть). Опасные команды (например удаление) **всегда** спрашивают.
- `/agent off` — чистый чат без действий.
- Команды вручную: `/run команда` или `!команда`, `/ls`, `/grep`, `/read файл`, `/git`.

### Комментарии (`/comments on|off`, по умолчанию включено)
Перед действиями ИИ коротко пишет, что собирается делать; для нового проекта — план со списком файлов, потом создаёт файлы. В коде появляются короткие комментарии. Перед выполнением показывается список действий.

### Рассуждение (`/think on|off`, по умолчанию выключено)
Включено — ИИ «думает вслух», это показывается серым. Выключено — рассуждение скрыто (у моделей, которые рассуждают сами, тоже).

## 7. Папка проекта и меню проектов

ИИ работает только в выбранной папке: файлы создаются и правятся там, команды запускаются там.

| Команда | Что делает |
|---|---|
| `/pwd` | где сейчас работает ИИ |
| `/cd` | обзор папок (номер — войти, `0` — вверх, `n имя` — создать, Enter — выбрать) |
| `/cd путь` | перейти в папку; `/cd -` — вернуться назад |
| `/projects` (или `/p`) | **меню проектов**: до 9 недавних, номер — открыть, `d 2` — убрать из списка, `a` — добавить текущую, `b` — обзор |

При смене папки программа предложит начать новый чат. На корне диска и в домашней папке просит подтверждение.

Чтобы ИИ знал правила проекта, создай в папке файл `FENTANYL.md` (или `CLAUDE.md`, или `AGENTS.md`) — его начало (до 8000 символов) подставляется в инструкции.

## 8. Автопроверка и предпросмотр

### Автопроверка (`/check off|warn|fix`)
После того как ИИ создал или изменил файлы, программа сама запускает проект и смотрит консоль.

| Режим | Что происходит при ошибке |
|---|---|
| **warn** (по умолчанию) | показывает ошибку и спрашивает «Попросить ИИ исправить?» (Enter = да) |
| **fix** | сама отправляет ошибку ИИ, тот исправляет, проект перепроверяется (до 2 попыток) |
| **off** | ничего не запускает |

Что проверяется: Python и Node (синтаксис + запуск), shell-скрипты, HTML (битые ссылки на файлы).
Не считается ошибкой: программа работает дольше 8 секунд (сервер/игра — её останавливают), ждёт ввод с клавиатуры, требует графический экран.

**Безопасность:** код запускается только с твоего согласия — при первом запуске спросит `y` (один раз), `a` (всегда) или `n`. Запущенной программе не передаются переменные окружения с `KEY`, `TOKEN`, `SECRET`, `PASSWORD` (например твой ключ API). Время запуска и размер вывода ограничены.

### Окно предпросмотра (`/preview`)
- `/preview` — показать проект сейчас; `/preview файл` — конкретный файл; `/preview off|on` — выключить/включить автопоказ.
- Python / Node / sh — рамка с выводом программы и итогом (✓ или ✗, время).
- HTML — открывается в браузере через локальный сервер (только `127.0.0.1`, скрытые файлы вроде `.env` не отдаются). Нажми Enter, чтобы закрыть. Если браузер не открылся сам (например, в Termux) — открой показанный адрес вручную.

## 9. Внешний вид и мелочи

| Команда | Что делает |
|---|---|
| `/theme [имя]` | цветовая тема: `mint`, `sunset`, `ocean`, `grape`, `mono` |
| `/lang [en\|ru]` | **язык интерфейса** (без аргумента — меню выбора) |
| `/anim on\|off` | анимации (или запуск с `--no-anim`) |
| `/clear` | очистить экран (чат сохраняется) |
| `/name [имя\|-]` | сменить имя, `-` — убрать |
| `/idle <сек>` | когда засыпает котик (0 — выключить), `/cat` — показать |
| `/notify on\|off` | уведомление о долгих ответах |
| `/battery on\|off` | экономия батареи (Termux:API) |
| `/credits` | о программе |
| `/reset` | **сброс настроек**: 1 — вид и режимы (язык, имя, тема, проекты…), 2 — всё, включая ключ и модель. После сброса снова спросит язык и имя |

**Чат:** `/new` · `/paste` · `/file <путь>` · `@путь` · `/save <путь>` (сохранить последний блок кода) · `/compact` (сжать историю) · `/ctx [n]`
**Агент:** `/agent on|off` · `/auto edit|run|off` · `/undo` · `/run <cmd>` · `!cmd` · `/ls [путь]` · `/grep <regex> [путь]` · `/read <файл> [от-до]` · `/git [diff|log|commit]`
**Проект:** `/projects` · `/cd [путь|-]` · `/pwd`

**Модель:** `/models` · `/download <url>` · `/gguf [путь]` · `/server [stop|restart]` · `/model <имя>` · `/setup` · `/sys <текст>` · `/battery`
**Вид:** `/lang` · `/clear` · `/think` · `/comments` · `/theme` · `/anim` · `/idle` · `/cat` · `/notify` · `/name` · `/credits` · `/reset`

## 13. Если что-то не работает

| Проблема | Что делать |
|---|---|
| «не найден llama-server» | установи llama.cpp (раздел 5, GGUF) или выбери другой вариант в `/setup` |
| Ошибка ответа / ключа / адреса | `/setup` и проверь ключ, адрес, модель; для локальных — запущен ли сервер |
| «Connection refused» к Ollama / LM Studio | запусти программу и сервер; на телефоне вместо `127.0.0.1` укажи IP компьютера |
| Кракозябры, сломанные рамки | современный терминал (Windows Terminal, Termux, iTerm); или `--plain` |
| Лаги от анимаций | `/anim off` |
| После сбоя терминал «странный» | введи `reset` и Enter |
| ИИ не создаёт файлы, а только пишет код | модель слишком слабая для агента — возьми побольше или `/agent on`; код можно сохранить `/save путь` |
| «контекст почти заполнен» | `/compact` или `/new` |
| Браузер не открылся при предпросмотре | открой адрес из рамки вручную |
| Автопроверка не запускает код | согласись на запрос (`y` / `a`) или включи `/check warn` |
| Хочу сменить язык | `/lang en` или `/lang ru` |
| Хочу начать с чистого листа | `/reset` |

## 14. Из чего состоит программа

```
fentanyl/
├── fentanyl.py        точка входа
└── fcore/
    ├── term.py        цвета, темы, рамки
    ├── anim.py        логотип, анимации, шапка, приветствие
    ├── render.py      вывод ответа ИИ (перенос по словам, markdown)
    ├── workdir.py     выбор папки, меню проектов
    ├── greet.py       язык, имя и приветствия
    ├── i18n.py        переводы: tr()
    ├── lang_en.py     английские тексты интерфейса
    ├── checker.py     автопроверка и предпросмотр
    ├── config.py      настройки и подключение
    ├── api.py         запросы к ИИ
    ├── server.py      встроенный GGUF-сервер
    ├── models.py      каталог и скачивание моделей
    ├── agent.py       действия ИИ (создать/править/запустить)
    ├── tools.py       файлы, поиск, diff, подтверждения
    ├── session.py     контекст, @-файлы, сохранение чатов
    ├── chat.py        ход диалога, справка, статус
    ├── commands.py    все /команды
    ├── cat.py         котик
    ├── sysutil.py     уведомления, батарея, git
    └── app.py         ввод и главный цикл
```
Нашёл баг: в команде — `commands.py`; в ответе ИИ — `api.py` / `render.py`; в правках файлов — `agent.py` / `tools.py`; в проверке — `checker.py`.

## 15. Безопасность — коротко

- ИИ меняет файлы и запускает команды **только после твоего подтверждения** (кроме режимов `/auto` и автопроверки, которые ты включаешь сам).
- Автопроверка запускает код только с твоего согласия, без твоих ключей в окружении.
- Не включай `/auto run` на папках с важными данными и не выбирай корень диска как папку проекта.
- Делай копию важных проектов (или используй git): `/undo` откатывает только правки внутри текущей сессии.

Приятной работы! 🚀
